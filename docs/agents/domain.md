# Domain docs

BidBeacon is a single-context repository.

## Read before exploring

- Read root `CONTEXT.md` for the canonical domain vocabulary.
- Read every relevant decision under `docs/adr/`.
- Use the glossary's preferred terms in issues, specs, tests, and implementation.
- Surface any proposed contradiction with an ADR instead of silently overriding it.

Missing domain documentation is not itself an error. `/domain-modeling` creates or sharpens it when a real language or decision gap appears.
