# Recipe: optimize an existing resource

Turn evidence and account policy into one bounded proposal.

1. Search the resource's current setting and the evidence relevant to the requested outcome.
2. State the observed value, policy or objective, proposed absolute value, expected effect, and observation window. Narrow the claim when coverage or denominators are weak.
3. When profitability or seasonality matters, include aligned actual sales and royalties for affected ASINs; call royalties minus ad spend contribution, not profit.
4. For a recommendation, stop here.
5. For an action to apply, show the exact change and invoke the matching update operation at approval.
6. Confirm the canonical accepted result and say when performance should be evaluated.

Use reversible state changes where possible. Read [lifecycle](pause-or-archive.md) before terminal archive.

## Done

Report evidence, assumptions, proposed or accepted absolute value, resource ID, and observation window.
