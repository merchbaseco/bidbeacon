# Recipe: manage negative targeting

1. Search Targets in the relevant Campaign or Ad group to confirm scope and avoid duplicates.
2. Create an Ad-group negative keyword or ASIN with the matching operation, or archive an existing negative with `update_target`.
3. Confirm the accepted Target ID, scope, kind, and state.

Campaign-level negative creation is outside the public surface. Existing campaign negatives remain searchable and archivable. Broad exclusions deserve explicit confirmation because they can suppress useful traffic.

## Done

Report the Campaign and Ad-group scope, negative Target ID, keyword or ASIN, match type when applicable, accepted state, and any requested negative that could not be represented.
