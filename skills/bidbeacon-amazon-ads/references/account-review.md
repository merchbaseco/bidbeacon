# Recipe: review an Advertiser account

Start broad; spend detail only where it could change a decision.

1. Search Campaigns over an explicit review range using the default view or the smallest useful performance set. Compare an equal prior range when change matters.
   Use Account Performance when the review needs a complete trend rather than resource ranking.
2. Prefer ACoS unless asked otherwise. In a compact review, call out PAUSED Campaigns; enabled is implied.
3. Check coverage, then rank only material findings: delivery problems, waste, constrained winners, and large changes.
4. Drill into Campaign composition before acting on an aggregate outlier. Use [Campaign investigation](investigate-campaign.md).
5. For business performance, profitability, or halo questions, add one aligned MerchBase sales summary; break down only material ASINs.
6. Separate observations from policy judgments. Ask for missing objectives or limits before turning a finding into an optimization.

## Done

Report a compact winners, bleeders, and watch list, then at most three scoped actions with Campaign IDs, evidence, assumptions, and the best next question.
