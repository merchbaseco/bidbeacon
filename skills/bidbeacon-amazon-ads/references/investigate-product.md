# Recipe: investigate an ASIN

Trace ASIN performance to the resources an agent can inspect or change.

1. Search Product performance for the ASIN. Compare an equal prior range when change matters; request Product Performance only when its temporal history is needed.
2. Search Ads for the same ASIN to obtain Ad, Ad-group, and Campaign IDs.
3. For a performance decision, read the same ASIN's MerchBase listing and aligned actual sales and royalties. Use RankWrangler only when demand or listing uncertainty remains.
4. Inspect only implicated Campaigns or Targets needed to explain delivery, traffic, conversion, or targeting.
5. Keep Product, Ad, Campaign, and Target performance as distinct grains.

## Done

Report the ASIN, material finding, implicated Campaign and Ad IDs, and whether evidence points to delivery, traffic, conversion, targeting, or insufficient data.
